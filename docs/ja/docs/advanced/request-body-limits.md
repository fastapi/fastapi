# リクエストボディの制限 { #request-body-limits }

アプリが小さな JSON リクエストを受け取る一方で、ユーザーにはより大きなファイルもアップロードさせたい、という場合を考えてみてください。

`FastAPI` アプリを作成するときに、`max_body_size` をバイト単位で設定できます。さらに、`APIRouter` ごと、または単一の *path operation* ごとに異なる制限を設定できます。

{* ../../docs_src/request_body_limits/tutorial001.py hl[3:4,17] *}

* `POST /items` は、アプリの制限である 1 MiB（`1024 * 1024` バイト）を使用します。
* `POST /uploads/` は、ルーターの制限である 100 MiB を使用します。
* `POST /uploads/small` は、独自の制限として 10 MiB が適用されます。

## 制限の対象になるもの { #what-counts-toward-the-limit }

制限は**リクエストボディ全体**に適用されます。同じリクエストで2つのファイルをアップロードした場合、両方のファイル、すべてのフォームフィールド、multipart フォームのエンコードに使われるバイトは、すべてその1つの制限の対象として数えられます。URL とリクエストヘッダーはボディの外側にあります。

**FastAPI** は、クライアントが `Content-Length` ヘッダーなしでボディをチャンク送信した場合でも、読み取ったバイトを数えます。読み取りが制限を超えた場合、FastAPI は読み取りを停止し、レスポンスがまだ開始されていなければ HTTP **413 Content Too Large** レスポンスを返します。

*path operation* が自分でボディを読み取る場合、FastAPI が合計サイズを把握する前に実行が始まることがあります。たとえば、アップロードを一時ファイルへストリーミングしている場合は、ファイルを公開する前に読み取りを終えてください。

[`UploadFile`](../tutorial/request-files.md#file-parameters-with-uploadfile) を使うと、ファイルは大きくなるにつれてメモリからディスクへ移動することがあります。その内容も、同じ制限の対象として数えられます。

## ルーターのデフォルトを設定する { #set-a-default-for-a-router }

`include_router()` に `max_body_size` を渡すこともできます。取り込まれたルーターは、独自の制限を宣言していない限り、そのデフォルトを使用します。*path operation* は常により小さい、またはより大きい独自の制限を宣言できます。

`max_body_size` をデフォルトの `None` のままにすると、それを含むルーターまたはアプリから制限を引き継ぎます。マウントされたアプリも、親アプリの制限を同じ方法で引き継ぎます。どこにも制限を設定しない場合、FastAPI はボディサイズを無制限のままにします。バイト数には正の整数を使い、空のボディだけを許可する場合は `0` を使います。

/// note | ボディを読み取るミドルウェア

ミドルウェアが、FastAPI が *path operation* を選択する前にボディを読み取る場合、その読み取りにはアプリの制限が適用されます。上記の例では、`await request.body()` を呼び出すミドルウェアは、100 MiB を許可するルーターに到達する前に、2 MiB のアップロードを拒否します。

ミドルウェアがリクエストをマウントされたアプリに渡す場合、すでに読み取られたバイトには、マウントされたアプリの制限も適用されます。

ミドルウェアでそれらのアップロードを読み取る必要がある場合は、アプリの制限を十分に大きく設定し、より小さい制限が必要な *path operations* には、それぞれ小さい制限を設定してください。

///

## フォームフィールドとファイルの制限を設定する { #set-limits-for-form-fields-and-files }

フォームフィールドとファイルの制限は、`form_limits` 設定で指定できます。

各設定は個別に引き継がれるため、アプリ、ルーター、`include_router()`、または単一の *path operation* で、必要な制限だけを上書きできます。

{* ../../docs_src/request_body_limits/tutorial002.py hl[5,13] *}

* `max_fields` は、テキストフィールドの最大数を設定します。デフォルトは 1,000 です。
* `max_files` は、multipart フォーム内のファイルの最大数を設定します。デフォルトは 1,000 です。
* `max_part_size` は、各テキストフィールドの最大サイズをバイト単位で設定します。デフォルトは 1 MiB です。URL エンコードされたフォームでは、Starlette はエンコードされた名前と値を合わせて数えます。

FastAPI は、依存関係内のパラメータも含め、`Form`、`File`、または `UploadFile` パラメータのためのリクエストをパースするときに、これらの設定を Starlette に渡します。パーサーの制限を超えると HTTP 400 が返されます。アップロードされたファイルの内容も含め、リクエスト全体を制限するには `max_body_size` を使用してください。

自分でフォームをパースする場合は、最初の `request.form()` 呼び出しに制限を渡してください。Starlette は、パースしたフォームをそのリクエストにキャッシュします。

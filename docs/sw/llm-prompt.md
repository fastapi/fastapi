### Target language

Translate to Swahili (Kiswahili).

Language code: sw.

### Grammar

Use clear, natural Swahili. Preserve existing translations that are understandable and technically correct, even if terminology varies. Prioritize meaning over uniform wording.

Use correct noun-class agreement, for example "uga uliotangazwa" (one field) and "nyuga zilizotangazwa" (multiple fields).

Avoid repeating identical Swahili phrases when translating synonyms together. Preserve distinct concepts and separate glossary entries.

---

The following guidance prevents misleading translations. Other clear equivalents are acceptable.

For concurrency, parallelism, I/O bound, and CPU bound, prefer the English terms over literal translations that blur their meanings.

* authentication: uthibitishaji wa utambulisho.
* authorization: uidhinishaji.
* compiled language: lugha inayotumia compiler.
* data validation: uhakiki wa uhalali wa data.
* deployment: making an application available to run; this does not necessarily mean production.
* dummy hash: hash mbadala (a placeholder, not a test hash).
* exit code / teardown code (dependency cleanup, not process exit status): msimbo wa kuachilia rasilimali.
* parameter / parameters: kigezo / vigezo.
* production environment: mazingira ya matumizi halisi.
* software development: uundaji wa programu. Use "usanidi" for configuration.
* subclass: a class derived from another class, not a smaller class.
* sub-dependency: kitegemezi cha kitegemezi kingine (a dependency relationship, not size).
* variable / variables: kigeu / vigeu.

# How To - Recipes { #how-to-recipes }

এখানে **বিভিন্ন topics**-এর জন্য নানা recipes বা "how to" guides দেখবেন।

এই ideas-গুলোর বেশিরভাগই কমবেশি **স্বাধীন**, আর বেশিরভাগ ক্ষেত্রে শুধু তখনই পড়লে চলবে যখন এগুলো সরাসরি **আপনার project**-এ কাজে লাগে।

কিছু যদি আপনার project-এর জন্য আগ্রহের আর কাজের মনে হয়, তাহলে দেখে নিন, না হলে সম্ভবত বাদ দিতে পারেন।

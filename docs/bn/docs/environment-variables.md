# Environment Variables { #environment-variables }

একটি **environment variable** (যেটা **env var** নামেও পরিচিত) হলো এমন একটি value যেটা আপনার Python code-এর বাইরে, operating system-এ থাকে, আর আপনার application ও অন্য programs সেটা পড়তে পারে।

FastAPI applications সাধারণত configuration-এর জন্য environment variables ব্যবহার করে, যেমন database URLs, email credentials আর secret keys।

application configuration-এর জন্য এগুলো কীভাবে ব্যবহার করতে হয়, সেটা শিখবেন [Settings and Environment Variables](advanced/settings.md)-এ।

## আরও জানুন { #learn-more }

বিস্তারিত, সব platform-এর জন্য ব্যাখ্যা পেতে [Environment Variables guide](https://tiangolo.com/guides/environment-variables/) পড়ুন, যেখানে environment variables কীভাবে বানাতে আর পড়তে হয়, আর `PATH` environment variable কীভাবে কাজ করে, সব আছে।

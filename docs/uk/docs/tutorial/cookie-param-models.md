# Моделі параметрів кукі { #cookie-parameter-models }

Якщо у вас є група **кукі**, які пов'язані між собою, ви можете створити **Pydantic-модель**, щоб оголосити їх. 🍪

Це дозволить вам повторно **використовувати модель** у **різних місцях**, а також оголосити валідацію та метадані для всіх параметрів одночасно. 😎

/// note | Примітка

Це підтримується з версії FastAPI `0.115.0`. 🤓

///

/// tip | Порада

Ця ж техніка застосовується до `Query`, `Cookie` та `Header`. 😎

///

## Заборона додаткових кукі { #forbid-extra-cookies }

У деяких спеціальних випадках (ймовірно, не дуже поширених) ви можете захотіти **обмежити** кукі, які хочете отримувати.

Ваш API тепер має можливість контролювати власну <dfn title="Це жарт, про всяк випадок. Це не має стосунку до згоди на кукі, просто кумедно, що навіть API тепер може відхиляти бідні кукі. Візьміть печиво. 🍪">згоду на кукі</dfn>. 🤪🍪

Ви можете використовувати налаштування моделі Pydantic, щоб `forbid` будь-які `extra` поля:

{* ../../docs_src/cookie_param_models/tutorial002.py hl[10] *}

Якщо клієнт спробує надіслати якісь **додаткові кукі**, він отримає відповідь з **помилкою**.

Бідні банери кукі, які так старанно намагаються отримати вашу згоду, щоб <dfn title="Це ще один жарт. Не звертайте на мене уваги. Випийте трохи кави до свого печива. ☕">API її відхилила</dfn>. 🍪

Наприклад, якщо клієнт спробує надіслати кукі `santa_tracker` зі значенням `good-list-please`, він отримає відповідь з **помилкою**, яка повідомить, що `santa_tracker` <dfn title="Санта не схвалює нестачу кукі. 🎅 Гаразд, досить жартів про кукі.">кукі не дозволено</dfn>:

```json
{
    "detail": [
        {
            "type": "extra_forbidden",
            "loc": ["cookie", "santa_tracker"],
            "msg": "Extra inputs are not permitted",
            "input": "good-list-please",
        }
    ]
}
```

## Поєднання моделей параметрів { #combine-parameter-models }

Ви можете поєднувати кілька моделей параметрів кукі з окремими параметрами кукі та залежностями. Дані для кожної моделі витягуються та валідуються незалежно, як пояснено для [моделей параметрів запиту](query-param-models.md#combine-parameter-models).

Налаштування `extra` кожної моделі застосовується до всіх параметрів кукі, включно з оголошеними в інших моделях або залежностях. З `extra="forbid"` будь-які кукі поза цією моделлю відхиляються. З `extra="allow"` ці кукі включаються як додаткові поля моделі.

## Необов'язкові моделі параметрів кукі { #optional-cookie-parameter-models }

Оголосіть модель параметрів кукі з `| None` і значенням за замовчуванням `None`, щоб зробити групу необов'язковою.

{* ../../docs_src/cookie_param_models/tutorial003.py hl[15] *}

Якщо не надіслано ні `theme`, ні `locale`, `preferences` має значення `None`. Якщо надіслано хоча б одне з них, FastAPI валідує модель і вимагає обидва поля.

Застосовуються ті самі правила щодо значень за замовчуванням, додаткових полів і OpenAPI, що й для [необов'язкових моделей параметрів запиту](query-param-models.md#optional-query-parameter-models).

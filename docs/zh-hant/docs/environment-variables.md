# 環境變數 { #environment-variables }

**環境變數**（也稱為 **env var**）是存在於 Python 程式碼之外、作業系統中的值，可以被你的應用程式和其他程式讀取。

FastAPI 應用程式通常使用環境變數進行設定，例如資料庫 URL、電子郵件憑證和秘密金鑰。

你將在[設定與環境變數](advanced/settings.md)中學習如何將它們用於應用程式設定。

## 了解更多 { #learn-more }
